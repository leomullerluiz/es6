# ES6

## English

This repository is a bilingual learning course covering ES6 (ECMAScript 2015) concepts through short, runnable JavaScript examples.

The full lesson content lives in the language-specific track: **[en-US/README.md](en-US/README.md)**.

Each language track contains the same three lesson categories:

- `built-ins/` — new built-in objects and APIs introduced in ES6
- `functions/` — function-related features (arrow functions, defaults, rest/spread, etc.)
- `syntax/` — new syntax (`let`/`const`, template literals, destructuring, classes, etc.)

These folders exist under both `en-US/` and `pt-BR/`, with each lesson as a numbered `aulaN.js` file.

## Português

Este repositório é um curso bilíngue que aborda os conceitos do ES6 (ECMAScript 2015) por meio de exemplos curtos e executáveis em JavaScript.

O conteúdo completo das aulas está na trilha específica do idioma: **[pt-BR/README.md](pt-BR/README.md)**.

Cada trilha de idioma contém as mesmas três categorias de aulas:

- `built-ins/` — novos objetos e APIs nativos introduzidos no ES6
- `functions/` — recursos relacionados a funções (arrow functions, parâmetros padrão, rest/spread, etc.)
- `syntax/` — novas sintaxes (`let`/`const`, template literals, desestruturação, classes, etc.)

Essas pastas existem tanto em `en-US/` quanto em `pt-BR/`, com cada aula em um arquivo numerado `aulaN.js`.
